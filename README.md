# theClef downloads

Installers for **theClef**, the set list and chart app for live bands. When the leader calls the
next song, every player's chart turns with them on their own phone, tablet or stage screen.

Learn more at **[theclef.app](https://theclef.app)**.

## Download

Get the newest **theClef-x.y.z-mac.dmg** from [Releases](https://github.com/AndyDufresne422/theClef-releases/releases/latest),
or from [theclef.app/download](https://theclef.app/download).

## Install

1. Open the downloaded disk image and drag **theClef** to your Applications folder.
2. Open theClef and choose the folder for your band's library.
3. Turn on **Share on Wi-Fi** in Settings, then show the band the QR code.

Players don't need to download anything. They join from any phone, tablet or laptop browser on
the same Wi-Fi with the passcode.
